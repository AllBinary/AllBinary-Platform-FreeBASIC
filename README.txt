                             AllBinary Platform FreeBASIC

What is it?

This repository contains code generated by the AllBinary Platform for support in FreeBASIC.  
This repo is used to allow developers to skip the FreeBASIC code generation step.

What are some example games with this FreeBASIC code?

https://allbinary.itch.io (The downloads with "-freebasic" in the filename are FreeBASIC only builds. Currently that only includes nothing. Also the FreeBASIC builds are not available on Google Play or other stores.)
